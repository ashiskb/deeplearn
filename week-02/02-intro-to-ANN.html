Function to compute a neuron’s output

Function to compute a neuron’s output

\[ \begin{align} \text{raw output of a neuron}, f(x) &=& \sum weight_i \cdot input_i\\ &=& w_1\cdot i_1 + w_2\cdot i_2 + \cdots \end{align} \]

Here, \(i_i\) is the \(i^{th}\) input signal to that neuron, and \(w_i\) is the associated weight of that input signal.

  • Then, we normalize this with the use of an activation function. For example, sigmoid(.). Therefore, the final output of the neuron is: \[ H(neuron) = sigmoid(\sum weight_i \cdot input_i) = sigmoid(f(x)) \]

Steps in a Feed forward network

Step 1: Compute the weighted sum (\(\Sigma\))

Step 2: Apply the activation function on the weighted sum (\(\phi\))

Step 3: Pass the activation output to the next neuron it is connected to.

Reasons to use activation functions

Reasons to use activation functions

  • An activation function essentially squashes the input and transforms it into an output value that represents how much a node should contribute (i.e., how much a node should fire)
  • Activation functions introduce non-linearity in the model to solve non-linear classification problems.
  • Activation functions limit the output of a node to a certain range. In most cases, reduce number of weights to learn.

Goal is to find optimum set of weights that gives you the best \(C\) score.

Using brute-force algorithm to solve for optimum set of weights might take millions of years.

So, here is Gradient Descent algorithm to solve it.

Gradient Descent Algorithm

  • A note on gradient descent algorithm to optimize a cost function, \(L\)

  • If slope, \(\dfrac{\partial L}{\partial w} \geq 0\)

    • we are on the right side of optimum, \(L\). So, we need to decrease \(w\) a little bit.

    • We do this using the gradient update:

    \[ w = w - \alpha \dfrac{\partial L}{\partial w} \]

    where, \(\alpha\) is called the learning rate.

  • If slope, \(\dfrac{\partial L}{\partial w} < 0\)

    • we are on the left side of optimum, \(L\). So, we need to increase \(w\) a little bit.

    • We do this using the same gradient update:

    \[ w = w - \alpha \dfrac{\partial L}{\partial w} \]

  • Please note, the above two gradient updates are actually the same statement.

But, this will work perfectly only if the \(C\) function is convex.

Creating the ANN structure

Creating the ANN structure

Parameters of an ANN

  • Input layer, Input nodes An input node contains the input of the network and this input is always numerical. If the input is not numerical by default, it is always converted.
  • Hidden layer, hidden nodes: A hidden layer is a lyer of nodes between input and output layers. There can be either a single hidden layer, or multiple hidden layers in a network. The more that exist, the deeper the learning that a network can perform. In fact, multiple hidden layers are what the term deep learning refers to.
  • Output layer, output nodes: An output node is a node within an output layer. There can be a single or multiple output nodes depending on the objective of the network. For example, for a network to classify cat and dog from a pool of images, then there would be 2 output nodes.
  • Weight values: A weight is a variable that sits on an edge between two nodes. It may reflect the contribution/importance of nodes to accomplish the objective.

  • Bias nodes, Bias values: A bias is an extra node added to each hidden and output layer. It connects to every node within each respective layer. A bias is never connected to a previous layer, but is simply added to the input of a layer. It typically has a constant value of 1 or -1, and also has a weight on its connecting edges which also needs to be trained.

And, suppose the inputs are: \(x_1=x_2=0\), Without the bias node, only one output value is possible, which is 0. It may lead to a very poor fit of the given dataset - Bias enables activation function to be shifted to the left or right; i.e., make the offset between multiple node outputs 0.

  • Learning rate: It is a value that speeds up or slows down how quickly the gradient descent learns.

Forward propagation: Summation Operator, \(\Sigma\)

  • netinput of a node = the weighted bias + the weighted sum of the inputs \[ \text{netinput} = 1*bw_j + \sum_{i=1}^n{ x_iw_i} \]

\[ \begin{align} netb_1 &=& 1*bw_1 + a_1w_1 + a_2w_3\\ b_1 &=& \phi(netb_1) \end{align} \]

\[ \begin{align} netb_2 &=& 1*bw_2 + a_1w_2 + a_2w_4\\ b_2 &=& \phi(netb_2) \end{align} \]

\[ \begin{align} \nonumber netc_1 &=& 1*bw_3 + b_1w_5 + b_2w_6\\ \nonumber c_1 &=& \phi(netc_1) \end{align} \]

\[ \begin{align} \nonumber netc_1 &=& 1*bw_3 + b_1w_5 + b_2w_6\\ \nonumber Z &=& \hat{y} = \phi(netc_1) \end{align} \] * \(\hat{y}\) is an estimated predicted value yield at the output layer.

Calculating the total error: the cost function

  • In order for a neural network to successfully train:
    • It must minimize the difference between its actual output and the target output to find the global minimum (or a local minimum that is close enough to the global).
    • This difference is the total error, which essentially tells us how wrong a network is at the moment.
  • A cost function (also known as loss function) gives us the sense of the total error between the target output and actual output.

Types of cost functions

  • Say, we have an \(n\) sample dataset:
    • \(y_i\) is the ground truth output value of the \(i^\text{th}\) sample, and \(\hat{y}_i\) is the predicted output value of that sample:
  • Here is a list of few popular cost functions:

1. Mean Squared Error (MSE):

\[ MSE(y,\hat{y}) = \dfrac{1}{n} \sum_{i=1}^n (\hat{y}_i-y_i)^2 \]

2. Root Mean Squared error (RMSE):

\[ RMSE(y,\hat{y}) = \sqrt{\dfrac{1}{n} \sum_{i=1}^n (\hat{y}_i-y_i)^2} \]

3. Cross-Entropy Loss function (CE):

\[ CE(y,\hat{y}) =-\frac{1}{n}\sum_{i=1}^n y_i\log {\hat {y_i}} \]

4. Kullback-Leibler Divergence Loss (KL Divergence)

\[ KL(y || \hat{y}) = \frac{1}{n}\sum_{i}^n y_i\log\left(\frac{y_i}{\hat{y}_i}\right) \]

And, there are many other cost functions

  • MAE (\(L_1\)) loss,
  • Huber loss,
  • Negative Log Likelihood loss,
  • etc.

Calculating the gradients

  • We need to discover how the total error is spread across every weight in the ANN so that we can adjust the weights to minimize the error.

  • To do this, we are going to compute the error of every weight in the network.

  • The error of a weight is technically its analytical gradient (in other words, its first order derivative).
  • Once calculated, the ANN tries to minimize the errors and thus minimize the total error.
  • This algorithm is called Backpropagation algorithm.

Review: Partial Derivative

  • A derivative provides the slope of a tangent line at a single point.
  • A partial derivative is the derivative of a function which has 2 or more variables but with respect to a single variable. All the other variables are treated as constant.

In Backpropagation, we go backwards to compute gradients

We do forward pass first

  • Some notations to remember:
    • \(s_j\) is the pre-activation (weighted sum before the activation function is applied) of neuron \(j\).
  • Define the weighted sums at the two hidden neurons as:

\[ s_{b_1}=bw_1+w_1a_1+w_3a_2 \]

\[ s_{b_2}=bw_2+w_2a_1+w_4a_2 \]

  • Let’s use hidden layer activation function is \(f(\cdot)\):

\[ b_1=f(s_{b_1}) \]

\[ b_2=f(s_{b_2}) \]

  • For the output neuron,

\[ s_c=bw_3+w_5b_1+w_6b_2 \]

  • and if its activation is \(g(\cdot)\),

\[ c_1=g(s_c) \]

  • Therefore, the final network output is

\[ Z=c_1. \]

  • So the network is essentially

\[ (a_1,a_2) \rightarrow (b_1,b_2) \rightarrow c_1. \]

Let’s Define the Squared-error Loss function

  • For one training example, with target \(y\), it is convenient to use half of the squared error:

\[ \boxed{L=\frac12(c_1-y)^2} \]

  • The \(\frac{1}{2}\) is included only to make the derivative cleaner.

  • Without the \(\frac{1}{2}\) factor,

\[ L=(c_1-y)^2, \]

everything below gets an extra factor, 2, to carry in subsequent derivative calculations.

Start Backward at the output and hidden layer weights

We want gradients such as

\[ \frac{\partial L}{\partial w_5}. \]

We could repeatedly write the full chain rule:

\[ \frac{\partial L}{\partial w_5} = \frac{\partial L}{\partial c_1} \frac{\partial c_1}{\partial s_c} \frac{\partial s_c}{\partial w_5}. \]

Let’s calculate each piece.

From

\[ L=\frac12(c_1-y)^2, \]

we get

\[ \frac{\partial L}{\partial c_1}=c_1-y. \]

Since

\[ c_1=g(s_c), \]

\[ \frac{\partial c_1}{\partial s_c}=g'(s_c). \]

And since

\[ s_c=bw_3+w_5b_1+w_6b_2, \]

\[ \frac{\partial s_c}{\partial w_5}=b_1. \]

Therefore

\[ \frac{\partial L}{\partial w_5} = \boxed{(c_1-y)g'(s_c)}b_1. \]

Similarly, we compute:

\[ \frac{\partial L}{\partial w_6} = \boxed{(c_1-y)g'(s_c)}b_2. \]

Notice that the first two terms appear repeatedly in calculations of the two gradients:

\[ \boxed{(c_1-y)g'(s_c)}. \]

This motivates us in defining the output delta

\[ \boxed{ \delta_c = \frac{\partial L}{\partial s_c} = (c_1-y)g'(s_c) } \]

Now the gradient becomes simply

\[ \boxed{ \frac{\partial L}{\partial w_5}=\delta_c b_1 } \]

and similarly

\[ \boxed{ \frac{\partial L}{\partial w_6}=\delta_c b_2 } \]

For the bias,

\[ s_c=bw_3+w_5b_1+w_6b_2 \]

\[ \frac{\partial s_c}{\partial bw_3}=1, \]

and,

\[ \frac{\partial L}{\partial bw_3} = \frac{\partial L}{\partial c_1} \frac{\partial c_1}{\partial s_c} \frac{\partial s_c}{\partial bw_3}. \]

so

\[ \boxed{ \frac{\partial L}{\partial bw_3}=\delta_c } \]

This is our first major simplification.

Why delta is useful?

Without delta, we would write

\[ \frac{\partial L}{\partial w_5} = (c_1-y)g'(s_c)b_1 \]

\[ \frac{\partial L}{\partial w_6} = (c_1-y)g'(s_c)b_2 \]

\[ \frac{\partial L}{\partial bw_3} = (c_1-y)g'(s_c). \]

Instead, we now can calculate

\[ \delta_c=(c_1-y)g'(s_c) \]

once, then reuse it:

\[ \boxed{ \begin{aligned} \frac{\partial L}{\partial w_5}&=\delta_cb_1\\ \frac{\partial L}{\partial w_6}&=\delta_cb_2\\ \frac{\partial L}{\partial bw_3}&=\delta_c \end{aligned}} \]

This becomes increasingly valuable in a large network.

Now move backward to hidden neuron \(b_1\)

This is where backpropagation becomes particularly interesting.

We want, for example,

\[ \frac{\partial L}{\partial w_1}. \]

The dependency path is

\[ w_1 \rightarrow s_{b_1} \rightarrow b_1 \rightarrow s_c \rightarrow c_1 \rightarrow L. \]

Using the complete chain rule,

\[ \frac{\partial L}{\partial w_1} = \boxed{\boxed{\frac{\partial L}{\partial c_1} \frac{\partial c_1}{\partial s_c}} \frac{\partial s_c}{\partial b_1} \frac{\partial b_1}{\partial s_{b_1}}} \frac{\partial s_{b_1}}{\partial w_1}. \]

We already know

\[ \frac{\partial L}{\partial c_1} \frac{\partial c_1}{\partial s_c} = \delta_c. \]

Furthermore,

\[ s_c=bw_3+w_5b_1+w_6b_2, \]

so

\[ \frac{\partial s_c}{\partial b_1}=w_5. \]

And

\[ b_1=f(s_{b_1}), \]

so

\[ \frac{\partial b_1}{\partial s_{b_1}} =f'(s_{b_1}). \]

Therefore,

\[ \frac{\partial L}{\partial s_{b_1}} = \delta_c w_5 f'(s_{b_1}). \]

Again, this quantity will be reused, so we define another delta:

\[ \boxed{ \delta_{b_1} = \frac{\partial L}{\partial s_{b_1}} = w_5\delta_c f'(s_{b_1}) } \]

This is the hidden-layer delta.

Hidden neuron \(b_2\)

Exactly the same reasoning gives

\[ \boxed{ \delta_{b_2} = w_6\delta_c f'(s_{b_2}) } \]

Notice the beautiful backward pattern:

  • \(\delta_c\) is sent backward through \(w_5\) to \(b_1\): \(w_5\delta_c\)
  • \(\delta_c\) is sent backward through \(w_6\) to \(b_2\): \(w_6\delta_c\)

Then each hidden neuron multiplies that incoming error signal by its own activation derivative.

Thus

\[ \boxed{ \text{hidden delta} = \text{downstream delta} \times \text{connecting weight} \times \text{local activation derivative} } \]

This is essentially the heart of backpropagation.

Now, calculate gradients of \(L\) w.r.to \(w_1,w_2,w_3,w_4\)

Now things become very easy.

\[ \frac{\partial L}{\partial w_1} = \boxed{\boxed{\frac{\partial L}{\partial c_1} \frac{\partial c_1}{\partial s_c}} \frac{\partial s_c}{\partial b_1} \frac{\partial b_1}{\partial s_{b_1}}} \frac{\partial s_{b_1}}{\partial w_1}. \]

\[ \frac{\partial L}{\partial w_1} = \boxed{\delta_{b_1}} \frac{\partial s_{b_1}}{\partial w_1}. \]

For \(b_1\),

\[ s_{b_1}=bw_1+w_1a_1+w_3a_2. \]

Therefore,

\[ \frac{\partial s_{b_1}}{\partial w_1}=a_1 \]

and, similarly

\[ \frac{\partial s_{b_1}}{\partial w_3}=a_2. \]

Hence

\[ \boxed{ \frac{\partial L}{\partial w_1} = \delta_{b_1}a_1 } \]

\[ \boxed{ \frac{\partial L}{\partial w_3} = \delta_{b_1}a_2 } \]

and

\[ \boxed{ \frac{\partial L}{\partial bw_1} = \delta_{b_1} } \]

For \(b_2\),

\[ s_{b_2}=bw_2+w_2a_1+w_4a_2, \]

so

\[ \boxed{ \frac{\partial L}{\partial w_2} = \delta_{b_2}a_1 } \]

\[ \boxed{ \frac{\partial L}{\partial w_4} = \delta_{b_2}a_2 } \]

and

\[ \boxed{ \frac{\partial L}{\partial bw_2} = \delta_{b_2}. } \]

In summary: the entire backpropagation

The forward pass is

\[ \begin{aligned} s_{b_1}&=bw_1+w_1a_1+w_3a_2\\ b_1&=f(s_{b_1})\\[2mm] s_{b_2}&=bw_2+w_2a_1+w_4a_2\\ b_2&=f(s_{b_2})\\[2mm] s_c&=bw_3+w_5b_1+w_6b_2\\ c_1&=g(s_c) \end{aligned} \]

with

\[ L=\frac12(c_1-y)^2. \]

Then going backward:

Output delta

\[ \boxed{ \delta_c=(c_1-y)g'(s_c) } \]

Output-weight gradients

\[ \boxed{ \begin{aligned} \frac{\partial L}{\partial w_5}&=\delta_cb_1\\ \frac{\partial L}{\partial w_6}&=\delta_cb_2\\ \frac{\partial L}{\partial bw_3}&=\delta_c \end{aligned}} \]

Hidden deltas

\[ \boxed{ \delta_{b_1}=w_5\delta_cf'(s_{b_1}) } \]

\[ \boxed{ \delta_{b_2}=w_6\delta_cf'(s_{b_2}) } \]

Hidden-weight gradients

\[ \boxed{ \begin{aligned} \frac{\partial L}{\partial w_1}&=\delta_{b_1}a_1\\ \frac{\partial L}{\partial w_3}&=\delta_{b_1}a_2\\ \frac{\partial L}{\partial bw_1}&=\delta_{b_1} \end{aligned}} \]

and

\[ \boxed{ \begin{aligned} \frac{\partial L}{\partial w_2}&=\delta_{b_2}a_1\\ \frac{\partial L}{\partial w_4}&=\delta_{b_2}a_2\\ \frac{\partial L}{\partial bw_2}&=\delta_{b_2}. \end{aligned}} \]

If sigmoid activations were used in \(f(\cdot)\) and \(g(\cdot)\)

  • Sigmoid is a nice looking function.

\[ \begin{align} \sigma(x) &=&\dfrac{1}{1+e^{-x}} \end{align} \] So, let’s calculate \(\sigma'(x)\) : \[ \begin{align} \dfrac{d}{dx}\sigma(x) &=&\dfrac{d}{dx}\left[ \dfrac{1}{1+e^{-x}} \right]\\ &=& \dfrac{0(1+e^{-x}) - 1(0+e^{-x})(-1)}{(1+e^{-x})^2} \\ &=& \dfrac{e^{-x}}{(1+e^{-x})^2} \\ &=& \dfrac{1}{(1+e^{-x})}\cdot \dfrac{e^{-x}}{(1+e^{-x})} \\ &=& \sigma(x)\cdot \left[ \dfrac{1 + e^{-x} - 1}{(1+e^{-x})} \right] \\ &=& \sigma(x)\cdot \left[ \dfrac{(1 + e^{-x})}{(1+e^{-x})} - \dfrac{1}{(1+e^{-x})} \right] \\ &=& \sigma(x)\cdot ( 1 - \sigma(x)) \\ \end{align} \]

If sigmoid activations were used in \(f(\cdot)\) and \(g(\cdot)\)

\[ f(s)=\sigma(s) \]

has derivative

\[ \sigma'(s)=\sigma(s)(1-\sigma(s)). \]

Since

\[ b_1=\sigma(s_{b_1}), \]

we don’t even need \(s_{b_1}\) to calculate the derivative:

\[ f'(s_{b_1})=b_1(1-b_1). \]

Similarly,

\[ f'(s_{b_2})=b_2(1-b_2). \]

If the output also uses sigmoid,

\[ g'(s_c)=c_1(1-c_1). \]

The deltas become particularly simple:

\[ \boxed{ \delta_c=(c_1-y)c_1(1-c_1) } \]

followed by

\[ \boxed{ \delta_{b_1} = w_5\delta_c\,b_1(1-b_1) } \]

\[ \boxed{ \delta_{b_2} = w_6\delta_c\,b_2(1-b_2) } \]

Then every gradient is just

\[ \boxed{\text{gradient}=\text{delta at destination}\times\text{input}} \]

For example,

\[ \frac{\partial L}{\partial w_3} = \delta_{b_1}a_2. \]

Alright, the \(\delta\)’s save computation

\[ \boxed{ \delta_j= \frac{\partial L}{\partial (\text{weighted sum at neuron }j)} } \]

and it captures:

How much would the loss change if I slightly changed the weighted input entering this neuron?

Once we know that value, the individual weights are easy.

For a weight connecting neuron \(i\) to neuron \(j\),

\[ \boxed{ \frac{\partial L}{\partial w_{ij}} = (\text{activation from }i) (\text{delta at }j) } \]

or, even more memorably,

\[ \boxed{ \text{weight gradient} = \text{LEFT value} \times \text{RIGHT delta} } \]

So on the diagram:

\[ a_1 \xrightarrow{w_1} b_1 \]

gives

\[ \boxed{\frac{\partial L}{\partial w_1}=a_1\delta_{b_1}} \]

while

\[ b_1 \xrightarrow{w_5} c_1 \]

gives

\[ \boxed{\frac{\partial L}{\partial w_5}=b_1\delta_c}. \]

The only nontrivial part is computing the deltas.

The backward flow intuition

Starting at the right:

\[ \boxed{ \delta_c = \underbrace{(c_1-y)}_{\text{loss error}} \underbrace{g'(s_c)}_{\text{local derivative}} } \]

Then move left:

\[ \boxed{ \delta_{b_1} = \underbrace{\delta_c}_{\text{error from right}} \underbrace{w_5}_{\text{connection}} \underbrace{f'(s_{b_1})}_{\text{local derivative}} } \]

\[ \boxed{ \delta_{b_2} = \underbrace{\delta_c}_{\text{error from right}} \underbrace{w_6}_{\text{connection}} \underbrace{f'(s_{b_2})}_{\text{local derivative}} } \]

So the error is effectively being transported backward through the weights, with each neuron applying its own local derivative.

That is why the algorithm is called back-propagation.

General weight update equation

\[ w5_\text{new} = w5_\text{old} - \alpha\cdot \dfrac{\partial L}{\partial w5}\] Here, \(\alpha\) is the learning rate.

Batch gradient descent update

\[ \begin{align} w5_\text{new} &=& w5_\text{old} - \alpha\cdot\dfrac{\partial L}{\partial w5} \end{align} \]

Let’s extend with Deep Feedforward Networks

  • Also known as Feedforward Neural Networks, or Multilayer Perceptrons (MLP), or Deep Neural Networks

  • The goal of the network is to approximate some function \(f^*\).

    • For example, a classifier \(y=f^*(\mathbf{x})\) maps an input \(\mathbf{x}\) to a class \(y\).

  • The network defines a mapping \(y=f(\mathbf{x}; \mathbf{\theta})\) and learns the value of parameters \(\mathbf{\theta}\) that result in the best function approximation.

  • These models are called feedforward for a reason:

    • Information flows through the function being evaluated from \(x\), through the intermediate computations used to define \(f\), and finally to the output \(y\).

    • There are no feedback connections in which outputs of the model are fed back into itself.

    • Here, PLEASE DO NOT confuse it with the backpropagation algorithm to train the parameters \(\theta\) (i.e., the set of weights)

  • When feedforward neural networks are extended to include feedback connections, they are called recurrent neural networks

# Sigmoid Activation Function
def sigmoid(x):
    '''
    This function actually compute sigmoid over input, x

    Inputs: 
        x: input data
    Returns:
        returns sigmoid of x
    '''
    return 1 / (1 + np.exp(-x))

# Forward Propagation (for visualization)
def forward_propagation(X):
    global w5, w6, bw3, w1, w2, w3, w4, bw1, bw2

    sb2 = bw2 + X[0]*w2 + X[1]*w4

    b2 = sigmoid(sb2)
    sb1 = bw1 + X[0]*w1 + X[1]*w3
    b1 = sigmoid(sb1)
    sc = bw3 + b1*w5 + b2*w6
    c1 = sigmoid(sc)

    
    return c1,sc,b1,sb1,b2,sb2

def backward(c1, sc, b1, sb1, b2, sb2, x, y):

    # output layer - hidden layer
    delta_c = (c1-y)*c1*(1-c1)
    dw5 = delta_c * b1
    dw6 = delta_c * b2
    dbw3 = delta_c

    #hidden neuron b1
    delta_b1 = w5 * delta_c * b1 * (1-b1)
    dw1 = delta_b1 * x[0]
    dw3 = delta_b1 * x[1]
    dbw1 = delta_b1

    #hidden neuron b2
    delta_b2 = w6 * delta_c * b2 * (1-b2)
    dw2 = delta_b2 * x[0]
    dw4 = delta_b2 * x[1]
    dbw2 = delta_b2

    return dw5, dw6, dbw3, dw1, dw2, dw3, dw4, dbw1, dbw2

Training utility : the update weights function

def update_weights(dw5, dw6, dbw3, dw1, dw2, dw3, dw4, dbw1, dbw2):
    global w5, w6, bw3, w1, w2, w3, w4, bw1, bw2

    w5 = w5 - alpha * dw5
    w6 = w6 - alpha * dw6
    bw3 = bw3 - alpha * dbw3

    w1 = w1 - alpha * dw1
    w2 = w2 - alpha * dw2
    w3 = w3 - alpha * dw3
    w4 = w4 - alpha * dw4
    bw1 = bw1 - alpha * dbw1
    bw2 = bw2 - alpha * dbw2
    return w5, w6, bw3, w1, w2, w3, w4, bw1, bw2

    random.shuffle(indices)

    #stochastic gradient descent
    for i in indices:
        #pick a random sample
        a_X = X[i] #input
        a_y = y[i] #target
        
        # Forward propagate the sample through the network
        c1, sc, b1, sb1, b2, sb2 = forward_propagation(a_X)
    
        # Backward propagation to calculate gradients
        gradients = backward(c1, sc, b1, sb1, b2, sb2,a_X, a_y)

        # Update the weights of the network
        w5, w6, bw3, w1, w2, w3, w4, bw1, bw2 = update_weights(*gradients)
